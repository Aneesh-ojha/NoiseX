Stack

Technology

ML

Acoustic Classification

Feature extraction (ZCR, RMS energy, crest factor, kurtosis) identifies background threats like rotor wash, gunfire, or broadband noise to dynamically guide DSP parameters.

STFT

Spectral Subtraction

Short-Time Fourier Transform decomposes input frames into magnitude and phase spectra. Over-subtraction with a spectral floor suppresses continuous periodic noise while avoiding phase collapse.

DWT

Wavelet Denoising

Multi-resolution Discrete Wavelet Transform isolates high-frequency transient spikes. Soft subband thresholding eliminates impulsive artifacts without creating robotic distortion.

HW

PYNQ-Z2 Acceleration

Offloaded to the Xilinx Zynq-7000 (PYNQ-Z2) platform using high-throughput AXI4-Stream DMA, achieving 2.24 ms latency — a 638× speedup over pure software execution.

SYNTHESIS

Cascaded Synthesis

Sequential reconstruction couples spectral noise reduction with wavelet detail cleanup, ensuring speech envelope integrity and formant preservation.

AUDIO

High-Speed Codec

ADAU1761 SigmaDSP provides 24-bit / 48 kHz analog I/O. AXI DMA connects the codec directly to programmable logic for zero-copy, real-time streaming.
