PLATFORM

PYNQ-Z2 / Zynq-7020

FPGA + ARM Cortex-A9 heterogeneous architecture. Programmable Logic (PL) handles real-time deterministic DSP pipelines, while the Processing System (PS) handles supervision and ML guidance.

Processing Logic (PL): Real-Time DSP
Processing System (PS): Supervision / ML
TRANSFORM

STFT / FFT

1024-point Fast Fourier Transform engine creating frequency-domain representations. Deconstructs raw audio frames into separate magnitude and phase spectra for non-destructive processing.

Transform Size: 1024-Point FFT
Domain Rep: Magnitude + Phase
DSP FILTER

Spectral Subtraction

Applies adaptive noise-spectrum estimation dynamically. Incorporates calibrated spectral floor and attenuation controls to eliminate stationary disturbances without generating musical artifacts.

Noise Estimation: Adaptive Spectrum
Floor Control: Spectral Floor Limit
WAVELET

DWT / Wavelet Denoising

Multi-level decomposition using the Daubechies 10 (db10) wavelet basis. Implements soft-thresholding across subband detail coefficients to clean non-stationary impulse and transient noise.

Wavelet Family: Daubechies db10
Threshold Mode: Soft-Thresholding
ML CLASSIFIER

ARM Cortex-A9 + ML

Performs real-time feature extraction (RMS, spectral centroid, ZCR, spectral flux) on ARM. A lightweight model classifies disturbances and accesses a Policy LUT to set optimal DSP parameters.

Extracted Features: RMS, Centroid, ZCR, Flux
Policy Control: Policy LUT → DSP Registers
AUDIO I/O

ADAU1761 + I²S

24-bit / 48 kHz low-noise audio codec. Handles microphone input capture and DAC/headset output streaming directly into FPGA fabric through dedicated I²S audio bus lines.

Resolution & Rate: 24-Bit / 48 kHz
Bus Protocol: Direct I²S Line/Mic IO
