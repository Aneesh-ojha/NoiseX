Stack

Technology

01 — ML

Machine Learning

Feature extraction (ZCR, RMS, crest factor, kurtosis) combined with a heuristic classifier identifies the noise environment category to guide DSP parameter selection.

02 — STFT

Spectral Subtraction

Short-Time Fourier Transform converts each audio frame into the frequency domain. A noise floor estimate is subtracted from the magnitude spectrum, then the signal is reconstructed via ISTFT.

03 — Wavelet

Wavelet Processing

Multi-resolution decomposition separates signal components at different time-frequency scales. Soft thresholding suppresses transient and broadband noise while preserving speech formants.

04 — HW

PYNQ-ZU Hardware

The pipeline is hardware-accelerated on the PYNQ-ZU (Zynq UltraScale+ MPSoC based platform) FPGA fabric via AXI4-Stream DMA, achieving 2.24 ms latency — a 638× speedup over pure software.

05 — RLS

Adaptive Filtering

Recursive Least Squares (RLS) adaptive filtering provides rapid convergence (<95 iterations) and the highest SNR gain among evaluated algorithms (23.70 dB with PSO-optimized coefficients).

06 — Audio

Audio Codec

ADAU1761 SigmaDSP (24-bit / 96 kHz) provides analog I/O. AXI DMA bridges the codec to the programmable logic for zero-copy high-throughput audio streaming.
